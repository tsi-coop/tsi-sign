Admin Console

Settings

Deployment-wide storage backend config. Admin only. Any field left blank falls back to its equivalent environment variable - a deployment that never touches this screen keeps working exactly as it does today.

Default Storage Backend

Leave blank to fall back to DEFAULT_STORAGE_PROVIDER_ID (default: local_fs). An individual App can still override this from its own App Detail page.

S3-Compatible Storage

Covers AWS S3 and self-hosted S3-compatible stores (MinIO, Ceph RGW, R2) - same client, endpoint URL is the only difference.

TSI Privacy Vault

Delegates document storage to a co-deployed TSI Privacy Vault instance.
